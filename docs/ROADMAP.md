# ininet-win — Roadmap (Windows-версия)

Поэтапная разработка, каждый этап — рабочий результат. Windows-first в этом репозитории.
Адаптировано под особенности Windows (права, API, кодировки, терминал).

**Статус: Этапы 0–9 завершены.** Проект рабочий, собирается в `.exe`, релизится по
тегу, покрыт тестами и CI. Этап 10 (алерты и публичный релиз) оставлен как future.

## Windows-специфичные заметки

- **Кодировка консоли**: всегда настраивать UTF-8 (`chcp 65001` / `PYTHONUTF8=1`),
  иначе кириллица ломается. `rich` помогает, но проверять на реальном conhost.
- **Права**: не требовать админа без нужды. Все, что можно — работает без elevation.
- **Firewall/Defender**: сканирование сети может вызвать уведомления — документировать.
- **Терминал**: основной таргет — Windows Terminal; conhost — вторичный, но проверять.
- **Портативность**: БД и кэш ТОЛЬКО в `%LOCALAPPDATA%\ininet`, не рядом с .exe.
