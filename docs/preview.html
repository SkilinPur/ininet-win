 Usage: ininet-win [OPTIONS] COMMAND [ARGS]...

 Network scanner & live connection monitor (Windows).

┌─ Commands ──────────────────────────────────────────────────────────────┐
│ version     Show the ininet-win version.                                │
│ admin       Show privilege status (administrator or not).               │
│ interfaces  List local network interfaces and their networks.           │
│ scan        Scan a network for live hosts and open ports.               │
│ history     List saved scan snapshots.                                  │
│ diff        Compare two saved scans: what changed between them.         │
│ watch       Watch live network connections (read-only).                 │
│ top         Show top processes by number of connections.                │
│ lang        Show or change the interface language.                      │
└─────────────────────────────────────────────────────────────────────────┘
